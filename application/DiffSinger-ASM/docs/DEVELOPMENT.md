# 完整编辑器实现清单

目标保持为完整的 DiffSinger 专属虚拟歌姬编辑器。一次功能迭代或一组测试通过，不代表完整产品完成。现有 OpenUtau 歌曲用于验证迁移、实际创作和合成效果；歌声推理始终来自 `application/diffsinger` 中的原生引擎。

| 创作环节 | 当前能力 | 必须继续实现/验证 |
| --- | --- | --- |
| 音符与歌词 | 添加、移动、转调、时长、框选、复制、UTF-8/中日文 IME、撤销、手绘音高与五条控制曲线 | 批量歌词分配、完整发音规则、颤音、逐音符模型参数 |
| DiffSinger 前端 | 声库词典/语言/元音类型、中文拼音、日文假名/汉字、英文词典、音素提示、音节连音与元音延音、当前音节真实音素显示、多音节 `+` 组独立时长、延音时长归属、确定性时长与 ASM F0 | 音素边界拖动、提前起音/学习对齐、神经网络 duration / variance / pitch 契约和实际歌曲发音/听感验收 |
| 声库与声线 | 验证当前原生打包模型，切换声库/声线/实际语言，逐音素语言编号，工程保存参数 | 每轨/每片段声库与声线、声线混合、模型能力驱动的参数面板、缺失资源恢复 |
| 编曲 | 多轨/多歌声片段、静音/独奏、轨道音量/声像、时间轴滚动和缩放 | 歌声片段移动/复制/裁剪/删除/重命名、轨道管理、变速/拍号时间轴、MIDI 和旧 UST 导入 |
| 音频 | WAV/FLAC 读取、重采样、波形、片段移动/裁剪/淡入淡出/删除/重新链接，撤销与保存 | 更多通道/格式实际验收、独立波形资源缓存、跨机器媒体打包、片段复制、音轨管理 |
| 合成与试听 | 原生 acoustic/vocoder 后台合成和取消，完整工程混音、伴奏独立试听、最新版本缓存、SDL 消费时钟、WAV 导出 | 逐片段缓存/失效范围、局部重合成、渐进预览、循环范围/自动跟随、长歌曲/反复编辑稳定性 |
| 工程迁移 | 25 个本机 USTX 的编辑数据及完整原文保留，音频字段生效，事务式原生保存重开、源媒体保护 | 未适配表情/音素覆盖/声线语义、需要时导出编辑后的 USTX、保存版本迁移、自动恢复/崩溃恢复 |
| 验收 | ASM/C 数值和交互测试、ASan/UBSan、实际引擎张量/PCM、真实 SDL/Vulkan、真实歌曲来源哈希 | 实际发音/对齐/听感、物理音频设备、完整歌曲编辑到导出的连续工作流、长期可靠性 |

继续补齐 duration/variance 模型和实际歌曲对齐，完善音素边界操作与编曲/合成迭代。每项完成都要更新其行为、验证命令和实际覆盖范围，不能用有效 PCM 或截图推断未验证的歌声质量。当前前端规则见 [FRONTEND.md](FRONTEND.md)，验收记录见 [VALIDATION.md](VALIDATION.md)。
