# 歌词、音素与时长

歌词解析和音素时长显示使用同一前端，合成任务另建相同配置的前端快照。词典在后台加载并缓存，选择音符后可在卷帘下方查看实际音素，在右侧修改读音与时长。右侧属性面板可滚动，小窗口中的时长和混音字段仍可操作。

## 语言与读音

「歌词语言」循环声库 `acoustic/languages.json` 中实际存在的语言，并切换该声库的 `dsdict-<code>.yaml`。语言编号来自该声库，不跨声库硬编码。合成写入与 tokens / durations 等长的 `languages.txt`；`ja/`、`zh/`、`en/` 等前缀确定对应音素语言，SP/AP/EP 等公共符号使用编号 0。没有语言嵌入的模型会忽略该条件。

中文汉字由 ICU 转拼音，再查声库词典。`ü` 在去调之前转为声库的 `v` 写法，保留女/绿与努/卢的区别。日文支持平假名、片假名、半角假名、罗马字、促音、拨音、长音及词典支持的拗音；包含汉字时使用 UTF-8 MeCab IPA 词典的读音与助词发音列。汉字歧义仍需人工检查，可在读音栏填写假名或显式音素。

英文查当前声库的词典条目，不为词典外单词猜读音。需要混合语言时，可显式写词典中的 `en/world`、`zh/shi` 或声库音素。USTX 的 `歌词 [k a]` 提示优先使用括号中的实际音素，并验证声库符号；未知符号会显示具体名称。

## 连音

延音必须与同片段的前一个音符相接。`+~` / `+*` 延长当前音节的元音；普通 `+` 在多音节词中推进到下一音节，音节耗尽后继续延长最后一个元音。未分配到单独音符的剩余音节在最后一个普通音符中分配。延音保留各音符的音高，词尾辅音移到该延长音节结束处，辅音不会因每个延音音符而重新起音。

这是确定性前端：自动时长按词典元音类型分配，含元音的音符中辅音最多占 3 帧（约 34.83 ms），剩余时长在该音符内的元音间分配。它不等同于 OpenUtau 的神经网络音素对齐或其全部音素器行为。音符若不能容纳每个音素至少一帧，会报告具体位置；不丢弃音素来掩盖过短音符。

## 手工时长

只选择一个音符，在「音素时长 ms」中依次填写当前音节的音素时长，用一个 `*` 自动填满余量。例如 `ja/k ja/a` 可填 `80 *`。时长必须为正数，合计小于该音符长度，每个音素至少需要一个模型帧。`*` 可放在任一音素位置。

多音节词的每个普通 `+` 音符拥有自己的音素和时长，无需拆分歌词。例如「世界 / + / +」分别显示 `ja/s ja/e`、`ja/k ja/a`、`ja/i`，可以独立调整每个音节。`+~` / `+*` 继承当前音节；点击其时长栏会自动选择该音节的起始音符，「重置」也作用于该音节。元音延音加到最后一个可延长元音上，词尾辅音保持在延音之后。

时长保存为 480 PPQ tick，并记录当前音节实际音素的顺序签名。改变 BPM 时保持音乐拍数，毫秒显示随之变化。改变歌词或读音会恢复该词组各音节的自动时长；撤销会恢复全部原时长。切换声库/语言后，如果生成的音素不再匹配，前端会提示重置。缩短音符不能越过手工分配的时长。手工时长参与撤销、重做、整组独立复制粘贴和原生保存/重开。

原始 USTX 的 `phoneme_overrides` 仍保留在来源快照中，尚未转换为本编辑器的时长记录。

## 检查与诊断

无需启动窗口或推理，就能检查全部歌声片段：

```sh
./application/DiffSinger-ASM/build/diffsinger-asm \
  --project /home/fuurin/Music/白い雪/snow.ustx --check-lyrics

./application/DiffSinger-ASM/build/diffsinger-asm \
  --project song.dse --singer /path/to/voicebank --language ja --check-lyrics
```

输出 JSON 包含语言编号、每个音素的符号/模型 token/帧数，以及片段和音符位置的诊断。合成也会先检查所有可听片段，再启动原生 acoustic/vocoder。失败会保留已有 WAV。任务目录保留 `phonemes.txt`、`tokens.txt`、`durations.txt`、`languages.txt`、ASM F0、参数文件和原生引擎日志。

本机 `snow.ustx` 的两段歌声已通过前端预检。`fly.ustx` 在当前声库下仍有两个明确问题：声库没有 `en/EP` 音素，以及一个 `to` 音符只有 19 tick，不能分配两帧。预检不修改源歌曲，也不把前端通过当作整首歌曲的听感认证。

神经网络 duration / variance / pitch 模型、音素提前起音的学习对齐和实际发音/听感评估继续列入 [开发清单](DEVELOPMENT.md)。
