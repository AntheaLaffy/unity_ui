# DiffSinger-ASM 产品定位

DiffSinger-ASM 是基于 ASMUI 与 x86-64 汇编编辑核心的 DiffSinger 专属虚拟歌姬编辑器。唯一歌声引擎为 `/home/fuurin/asm/diffsinger`；界面、工程数据和合成流程围绕这个引擎的实际能力设计。用户已有的 OpenUtau USTX 工程是主要导入来源，编辑结果保存为本编辑器的 `.dse` 工程，TLP 继续作为交换兼容格式。

## 核心创作流程

1. 选择可用声库和声线，确认模型、词典与音素集合。
2. 编写旋律与歌词，检查和调整歌词对应的音素。
3. 编辑音高和模型支持的表现参数，观察它们对歌声的影响。
4. 合成、预览与修改，清楚显示任务状态和当前预览是否对应最新工程。
5. 保存可继续编辑的工程，导出真实歌声 WAV。

现有版本已具备音符/歌词/实际音素显示和单音符时长编辑、手绘音高和参数曲线、后台合成/取消、版本化缓存、播放与 WAV 导出。支持中日文读音、英文声库词典、音节连音、元音延音与语言选择。伴奏具有波形、移动、裁剪、淡入淡出、音量/声像、独立试听及与歌声混音。自动时长使用确定性规则，工程共用一套声库与声线；神经网络时长与音高预测尚未接入。完整产品尚在实现，剩余工作与验收依据记录在 [开发清单](DEVELOPMENT.md)。

## 后续设计原则

- 声库能力决定控件与参数范围。模型采样率、音素集合、声线和必需文件应有明确的验证结果。
- 歌词、音素、音素时长与 F0 应能在同一编辑流程中检查和调整。扩展前端时，以实际声库支持的模型契约和真实歌曲验证为依据。
- 合成预览应服务反复修改。逐片段缓存、局部重合成和渐进预览需要正确处理版本、取消与播放时钟，再进入日常创作流程。
- 工程应能保存 DiffSinger 所需的声库、合成参数和后续音素编辑信息。以现有 USTX 歌曲验证迁移效果，保留原始信息并清楚呈现未支持语义；`.dse` 随编辑器能力发展，TLP 用于交换兼容。
- ASMUI 随编辑器需求持续改进，包括密集音符与曲线绘制、中文输入、缩放、面板布局和合成状态反馈。

这些方向是后续设计依据，具体已实现能力以 [README](../README.md) 和 [验证记录](VALIDATION.md) 为准。验收关注编辑可靠性、DiffSinger 输入/输出契约、发音、时长、音高与实际听感。
